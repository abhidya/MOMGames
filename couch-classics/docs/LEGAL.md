# Legal Rules

This repo is MIT-ready and must stay free of copyleft contamination unless the
owner explicitly chooses otherwise later.

## Source Code

- Write original code only.
- Do not paste third-party game source, decompiled source, AGPL/GPL source, or
  copied snippets into this repo.
- OpenPigeon is AGPL-3.0 and may be studied only for architecture patterns.
  Do not copy its code, scenes, assets, names, or expression.

## Assets

- Use original assets only.
- Placeholder art, audio, and fonts must be generated or created for this repo.
- Do not use ripped sprites, audio, fonts, icons, characters, or UI art.

## Naming

- Use original, generic names.
- Do not use real game titles, characters, brands, or logos.
- Mechanics and genres are acceptable references; expression and trademarks are
  not.

## Game Specs

Every new game starts with a spec in `docs/` using `GAME_SPEC_TEMPLATE.md`.
Implementation begins only after the state shape, move shape, and win condition
are reviewed.
